# 安裝與第一次使用

本套件以 `SKILL.md` 與相對路徑的 `references/` 組成，不需要老師的電腦、第二大腦、帳號或私人素材。

## 有 skill 安裝功能的 AI 工具

依目前工具提供的匯入方式，選擇 GitHub repo、完整資料夾或 `.skill`／ZIP 套件。不是每個工具都有「從 GitHub 匯入」，也不是把檔案丟進一般聊天就等於永久安裝。`.skill` 是 ZIP 格式的技能封裝；若平台要求 `.zip`，使用提供的 ZIP 版本。

匯入後新開對話，請 AI 顯示讀到的 skill 名稱與本次讀取的檔案，再做第一次測試。不要只看匯入成功通知。

## 使用 Claude Code 或 Codex 等本機 agent

請 agent：

> 請閱讀這個 skill 的 SKILL.md 與 references，依你目前支援的技能安裝方式安裝整個資料夾；先檢查同名 skill。已有版本先備份，確認專案與全域副本的優先順序，不直接覆蓋我的客製設定。完成後讀回實際安裝位置與 skill 名稱，再用附帶測試句執行一次。

手動安裝時，資料夾名稱使用 SKILL.md 的 `name`，並完整保留 references。不要只複製 SKILL.md，或把壓縮檔直接放入要求資料夾的技能目錄。

## 只有一般聊天或不支援安裝

上傳 SKILL.md 以及此次需要的 references，請 AI「本次對話依這些規則完成任務」。這是單次參考文件方式，不宣稱已永久安裝。只貼 GitHub 網址但工具不能讀網頁時，改提供檔案。

文字生成不需要圖片工具。輪播製圖則要有可用的圖片生成／編輯／排版功能；沒有工具仍可完成文案與素材規劃，PNG 製作留待有工具時完成。

## 第一次驗收

1. 提供主題、受眾、真實素材與目的。語氣樣本、配色、Logo 都可逐步補。
2. 指定 skill 名稱與此次交付物，先做一篇、一支或一套。
3. 檢查事實、口吻及待補欄位。輪播要求成圖時，逐頁打開，確認文字、順序與手機可讀性。
4. 發布由你決定。安裝工具不會自動幫你發文、私訊或領取贈品。

## 更新

備份原有客製版，再安裝新版。請 AI 讀回新版內容並確認同名副本，避免裝了新版卻仍讀舊版。對外教材不要包含自己的口述原件、客戶資料、帳密或品牌私密資料。
